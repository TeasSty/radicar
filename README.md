# RADICAR — сайт студии автосвета

Премиальный лендинг для [vk.com/radicar](https://vk.com/radicar) · Набережные Челны.

## Запуск

```bash
npm install
npm run dev
```

Открой http://localhost:5173/

```bash
npm run build   # сборка в dist/
npm run preview # превью продакшен-сборки
```

## Стек

Vite + HTML/CSS/JS. Шрифты: Syne + Manrope. Фото: материалы VK и галереи Яндекс Карт (см. `ASSET_SOURCES.md`).
